03

Shopping the route

No map. The people using this already know their own town, so the route is a checkpoint line: you, then each stop, with the distance between. Distances come from a hand-curated matrix of the eight Struga stores rather than a routing API, which is both more accurate and removes a native map dependency entirely. Opening hours come from the chains' own published store data.

Open questions

Substitutions. If Миса has no avocado, should the app silently offer a different brand, or always ask? The mockups assume ask.
Promo expiry. A promo ending tonight changes the whole recommendation tomorrow. Worth a warning badge on the route screen?
Default time value. 300 den/hour is a guess. It may be better to ship with time cost off and let people turn it on.
Walking radius. Should switching to walking automatically shrink the 3 km radius, or leave it to the person?

Decisions still to makeNone of these block the build, but all four change the UI, so they are worth settling before the components get written.
